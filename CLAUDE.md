# Fala Brasil — контекст проекта

Самоучитель бразильского португальского (pt-BR) для русскоговорящих. Аудитория — двое взрослых,
которые уезжают в Санта-Катарину: Иван и Анна. Уровень материала — с нуля до A1+.

## Главное правило

Всё приложение — **один файл `index.html`**: разметка, стили и JS внутри него. Сборки нет,
зависимостей нет, npm-пакетов нет. Не разбивай файл на модули и не добавляй бандлер без
прямой просьбы — файл открывается двойным кликом и этим ценен.

Единственный внешний запрос — шрифты Google (Unbounded, Golos Text, Spectral). Приложение должно
оставаться работоспособным и без них (прописаны системные фолбэки).

## Структура index.html

Сверху вниз:

1. `<title>`, `<meta name="claude:viewport-fit-sides">`, `<link>` на шрифты.
2. `<style>` — токены в `:root` (светлая тема), затем два блока тёмной темы:
   `@media (prefers-color-scheme: dark){:root:not([data-theme="light"])}` и `:root[data-theme="dark"]`.
   Любой новый цвет добавляй **токеном во все три блока**, не литералом в правиле компонента.
3. Разметка оболочки: боковая панель `.rail` (десктоп), `.topbar` + `.tabs` (телефон),
   четыре секции `#view-course`, `#view-review`, `#view-grammar`, `#view-phrases`,
   пустые контейнеры `#player-root` и `#modal-root`.
4. **Первый `<script>` — только данные**: `COURSE`, `GRAMMAR`, `PHRASES`.
5. **Второй `<script>` — вся логика** в одной IIFE.

## Формат контента

Слово и фраза — это массив `[pt, ru, транскрипция, альтернативы?]`. Четвёртый элемент —
допустимые варианты ответа при вводе с клавиатуры, через `|`.

```js
{n:'Comida e café', ru:'Еда и кафе', L:[
  {t:'Продукты',
   tip:['Заголовок подсказки','HTML-текст, показывается первым экраном урока'],
   w:[['água','вода','а́гуа']],              // новые слова
   s:[['Água, por favor.','Воды, пожалуйста.','а́гуа, пур фаво́р']],  // фразы
   d:[{q:'Eu ___ russo.',a:'sou',o:['sou','é','são'],ru:'Я русский.'}]} // дрилы на грамматику
]}
```

Правила контента:

- Португальский — **бразильский**, не европейский: `você`, `a gente`, `trem`→`ônibus`, Pix, R$.
- Транскрипция — русская, в бразильском чтении: конечное `o`→«у», `e`→«и», `de/te`→«джи/тчи»,
  начальное `r`→«х», конечное `l`→«у», `s` между гласными→«з». Ударение помечается знаком `́`.
- Во фразах урока используй слова этого же или пройденных уроков — упражнения берут
  неправильные варианты из общего словаря, и незнакомая лексика ломает логику сложности.
- В `d` поле `a` обязано присутствовать в `o`.

## Логика (второй script)

- `ITEMS` — индекс всех слов и фраз, ключ `'w|'+pt` или `'s|'+pt`. Это же id карточки в SRS.
- `st` — состояние активного профиля: `{xp, streak, lastDay, day, dayXp, lessons, cards, settings}`.
  `store` — обёртка со списком профилей; профили живут на устройстве.
- Хранение: `localStorage` под ключом `falabrasil.v1`, плюс синхронизация в базу артефакта
  claude.ai (`claude.use('db')`), когда страница открыта там. На GitHub Pages облако молча
  отключается — код обязан это переживать (`claude.use` обёрнут в try).
- SRS — вариант SM-2: `gradeCard(id, ok)`, интервалы в днях, при ошибке карточка возвращается
  через 10 минут и повторно вставляется в очередь текущего занятия через 3 позиции.
- Занятие — массив заданий `P.queue`, типы: `tip`, `teach`, `mc_pt`, `mc_ru`, `listen`,
  `build`, `type`, `gap`, `match`. Новый тип добавляется в трёх местах: генерация в
  `buildLesson`/`buildReview`, отрисовка в `drawQ`, проверка в `checkAnswer`.
- Озвучка — Web Speech API, голос `pt-BR`. На iOS звук не играет до первого касания:
  не убирай «прайминг» в обработчике `pointerdown`.

## Чего избегать

- `alert`, `confirm`, `prompt` — не работают внутри артефактов claude.ai.
- Горизонтальной прокрутки на ширине 400px и целей нажатия меньше 44px — приложением
  пользуются с iPhone.
- Правок только в светлой теме: проверяй обе.

## Проверка перед коммитом

Автотестов нет. Минимум: открыть `index.html` в браузере, пройти пару заданий урока,
проверить тёмную тему и ширину телефона в DevTools, убедиться, что в консоли пусто.

Для прогона в headless-браузере (если установлен Playwright):

```bash
node -e "const{chromium}=require('playwright');(async()=>{const b=await chromium.launch();
const p=await b.newPage({viewport:{width:402,height:874}});const e=[];p.on('pageerror',x=>e.push(x.message));
await p.goto('file://'+process.cwd()+'/index.html');await p.waitForTimeout(800);
console.log('errors',e, await p.evaluate(()=>document.documentElement.scrollWidth));await b.close()})()"
```
