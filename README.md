# Fala Brasil

Самоучитель бразильского португальского для русскоговорящих — одна HTML-страница, без сборки и зависимостей.

**Открыть:** https://chetverukhings.github.io/fala-brasil/

## Что внутри

- **30 уроков в 10 блоках** — от приветствий до прошедшего времени. В уроке чередуются форматы: карточка нового слова, выбор перевода в обе стороны, аудирование, сборка фразы из слов, ввод с клавиатуры, грамматический дрил, поиск пар.
- **Интервальное повторение** (алгоритм семейства SM-2) — слово возвращается тогда, когда его пора вспомнить; отдельно режим «слабые слова».
- **Озвучка** через системный голос pt-BR (Web Speech API), скорость 0,5–1,2×.
- **Грамматика и звуки** — 16 справок: чтение, носовые, ser/estar, слияния предлогов с артиклями, будущее через `ir`, pretérito perfeito, акцент Санта-Катарины.
- **Разговорник** — 10 тем для жизни в Бразилии: аренда, банк и CPF, аптека, транспорт, Pix, пляж, работа.
- **Профили** — несколько человек на одном устройстве, у каждого свой прогресс, словарь и серия дней.

## Как устроено

Весь код, контент и стили — в `index.html` (~120 КБ). Внешние запросы только к Google Fonts. Прогресс хранится в `localStorage` браузера: у каждого устройства он свой.

## Локально

Достаточно открыть `index.html` в браузере. На iOS первое воспроизведение звука нужно запустить касанием — таково ограничение Safari.
